# 🌸 Iris Flower Classification

This is a beginner-friendly machine learning project to classify iris flowers into three species:
- Setosa
- Versicolor
- Virginica

We used:
- `pandas` and `matplotlib` for data handling and visualization
- `scikit-learn` for training a **Logistic Regression** model

## 📘 Steps Covered
1. Load and explore the Iris dataset
2. Visualize feature relationships
3. Train a Logistic Regression model
4. Evaluate using accuracy and classification report
5. Visualize results with a confusion matrix
